Import a spreadsheet

Nexo imports tab-separated text files (.tsv in UTF-8, or .txt saved by Excel as "Unicode Text"). The first line is a header and is skipped.

Columns: Date, Account, Category, Subcategory, Note, Amount (main currency), Type (Income / Expense / Transfer-Out / Transfer-In), Description, and optionally Amount (original currency), Currency, Amount (account currency). A 12-column file exported by Nexo, with a Tag column after Type, is also accepted.

Accounts and categories must already exist. Rows with a problem are listed with the reason; tap them to fix or to create the missing account or category.
